# PHP Subscription App

## Quick start

1. Create a MySQL database, for example `dantes_subscriptions`.
2. Upload all files from this folder to your hosting root.
3. Configure DB credentials with environment variables:
   - `DB_HOST`
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASS`
4. Open `index.php` in browser.

The app auto-creates `users` and `subscriptions` tables on first run.
